# 写入、自动化与验收

原生 records / schema / automate 入口均显式调用。先固定目标，检查字段和当前值；批量记录以真实上限分批，逐项记录。数组通常表示新的完整值，保留未授权删除的关联 / 选择。ETag / compare-and-swap 只有服务实际支持才使用；读前值不构成并发锁。

自动化工具目录可能变化；草稿创建、配置更新、启用、运行结果分别记录。当前官方资料说明创建和修改保存为草稿；实际服务未提供开启工具时交付草稿 ID 和后续步骤。不要把自然语言计划当已运行自动化。

最小账户验收：工具发现 → 指定 base schema → 精确筛选 / 分页 → 授权测试记录写入及读回 → 权限不足 / 过期恢复。公开接口可达和本地协议测试不证明这些结果。
