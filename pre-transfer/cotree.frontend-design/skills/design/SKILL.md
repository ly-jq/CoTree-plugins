# 前端设计

遵循项目 AGENTS.md、用户当前授权和 CoTree 的权限 / 取消 / 会话恢复规则。先用 ToolSearch 读取实际工具 schema，再调用所需工具。主模型判断任务完成；测试输出和外部结果是证据，不能用自评分或固定审查轮数替代。只在任务需要且当前策略允许时使用 AgentDefinitions / AgentDelegate；模型继承宿主选择，不要求特定供应商。资源相对 Skill 返回的 skillDir 解析，插件根由 pluginRootDir 给出。

先确定用户目标、受众、主要操作和真实内容。读取现有路由、组件、样式、设计 token、字体与启动命令；现有产品沿用设计系统。只对会明显改变结果的缺失信息提问，其他选择用合理假设推进。

动手前简要说明布局、信息层级、颜色、字体和交互方向。独立新页面可以形成鲜明主题；已有页面优先保持一致。视觉选择要服务内容，不强制每个页面都使用同一套渐变、大标题、卡片或装饰。

通过 Read / Glob / Grep 定位代码，Edit / Write 实现。组件使用真实交互状态，包括加载、空数据、错误、禁用和成功状态。保证语义标签、关联 label、键盘路径、可见焦点、合理对比度及 prefers-reduced-motion。布局适配窄屏和长文本；避免溢出及隐藏关键操作。

先运行项目相关构建 / 类型 / 测试命令，再通过当前宿主提供的浏览器工具启动并检查桌面与移动视口。实际点击主要流程、用键盘操作并读取页面状态；截图只证明外观，不证明保存成功。缺少浏览器时记录检查范围，不宣称截图或交互已验收。

读取本目录 references/review.md 自检与任务有关的项目。交付改动文件、实际验证、必要截图和剩余问题；不自动部署。
