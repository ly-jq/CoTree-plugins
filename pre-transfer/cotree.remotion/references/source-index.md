# Remotion 来源技术索引

完整资料在 resources/source-01/content/skills，来源为 4.0.506 系列；顶层和 remotion-best-practices 下的嵌套参考均归档，只有本包十一项 Skill 注册。历史正文中的宿主指令和安装技能命令不继承。

- create：remotion-create（布局 / Tailwind）。compose：remotion-markup（3D、音频、timing、sequence、转场、字体、文本、参数、测量、effects、Lottie、动态元数据等）。
- media / captions：remotion-multimedia（Mediabunny 元数据）、remotion-captions（转写、SRT、显示）。
- maps：remotion-maps/techniques/{static-map,mapbox,maplibre,maptiler,cesium}；保留地理数据与渲染稳定性参考。
- interactive / preview / render：remotion-interactivity、remotion-studio、remotion-render（透明视频），渲染以本包禁止覆盖和元数据校验为准。
- app / docs / upgrade：remotion-saas（framework / player / rendering）、remotion-docs、remotion-upgrade。
