# shadcn 补充资料入口

这是 CoTree 的参考页，不注册第二个 Skill。实际入口为 cotree.vercel.ui，先读 [UI 使用说明](../ui.md)；同目录的来源快照不能覆盖当前项目指令，命令参数须核对项目所用 CLI 版本。

## Updating Components

更新现有组件时先读 components.json、当前文件与本地修改，确认 registry、基础库、别名、图标库和用户希望保留的行为。使用当前 CLI 支持的预览 / diff 能力列出受影响文件；来源中的 --dry-run / --diff 是候选参数，不强制下载 @latest。

逐文件比较上游变更与本地实现：无定制的文件可按任务范围更新；有定制的文件只合并需要的改动，保留调用合同、样式和可访问性。已有授权覆盖当前改动时直接执行，不加固定确认回合；丢弃定制或切换基础库超出授权时，先交付可审查差异再澄清。

切换 preset 时明确重装、合并或仅改配置的效果；临时比较环境必须使用与项目一致的基础库，preset 代码不能代替这项检查。变更后检查第三方组件的 import aliases、缺少的子组件、图标、类型和实际交互，保留用户原有未提交文件。
