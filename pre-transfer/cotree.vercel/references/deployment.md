# 部署证据

先确认工作区、团队、project ID、分支 / commit、预览或生产、未提交改动与当前配置，运行相关构建和测试。根据当前 CLI --help / MCP schema 使用实际入口，不复用原宿主发布工具。

预构建部署要关联产生它的版本与环境；部署返回 URL 后查终态，再验证用户路径。保护页需要正确授权，不能靠绕过保护制造页面成功。晋升 / alias / 域名和回滚按明确目标执行；回滚代码不回滚数据库和外部资源。

记录 deployment ID、URL、环境、版本、构建状态、业务检查和未确认项。超时先查询对象再恢复，避免重复部署。不要将输出链接或 READY 当成全流程已通过。
