# Android QA 与性能来源

resources/source-01/content/skills/android-emulator-qa包含流程、UI树与原Python摘要/首匹配脚本；原首匹配语义已由本包严格唯一选择器替代，旧脚本只归档。

android-performance完整保留Simpleperf、Perfetto/Compose、gfxinfo、meminfo、HPROF/Shark、heapprofd与两个POSIX报告脚本。本包不继承固定/tmp路径、清空logcat、覆盖/data/local/tmp/perf.data或全局kill采样进程；Windows使用参数数组、二进制输出和官方跨平台分析工具。

八项Skill补齐流程入口，设备执行和权限归现有Android插件/宿主。当前包与cotree.language-services/Expo的开发职责不同；不重复贡献设备MCP或后台loop。
