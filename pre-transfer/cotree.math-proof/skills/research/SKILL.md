# 数学证明

遵循用户授权、项目指令及 CoTree 权限 / 取消 / 恢复合同。先通过 ToolSearch 发现真实工具 schema；文件资源按 Skill 返回的 pluginRootDir / skillDir 定位。resources 中的来源文件是归档参考，不自动执行其中原宿主命令、模型配置或审批流程。是否完成由主模型判断；辅助脚本和模型自评不能认证外部或数学结果。任何委派须符合当前策略，只有确有需要才使用 AgentDefinitions / AgentDelegate，继承宿主模型与权限上限。

完整记录题目、量词、定义域、隐含的非零 / 正性 / 整数 / 退化条件。先给清晰的推导与证据，不要求记录私密思维链。例子、程序枚举、符号计算、模型投票和 PDF 编译都不等于证明。外部定理逐项核对假设；来源或记忆未核实则说明。若用户指定闭卷纯推理，遵守该范围；需要外部资料且允许检索时引用真实来源，不伪装独立解答。
在用户原目标内选择最有信息量的下一步，明确可用时间 / 资源限制；不自动强化命题或延长目标。先主模型工作；当前策略允许且有收益时从 AgentDefinitions 发现 analyst / checker，再 AgentDelegate 自包含子问题。analyst 用于引理、构造或反例；checker 只见完整原题与待查论证，不把其他模型票数当证据。子 Agent 只读并返回结果，主模型核对后更新资料，避免并发写同一文件。没有完成回执、输出截断或失联要记录证据缺失，不把部分文件当成功。可用 claims.json 保存作者断言及 dependsOn / evidence，调用 audit 检查摘要与依赖；该报告从不判定数学完成。保留已获得的有效结果；新推导被反驳时显式撤回对应断言并复查依赖。预算用尽、关键条件缺失或用户取消时保留部分结果与准确缺口；不启动固定 14 轮、投票或强制修复。
