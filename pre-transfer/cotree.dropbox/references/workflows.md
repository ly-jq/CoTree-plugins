# 文件、分享与后台任务

1. 先读取身份、namespace 和真实 ID/path。根目录必须从账户上下文取得，不按显示名称推断，跨命名空间操作需实际支持。
2. 搜索、目录、共享链接和文件请求各有独立分页合同；有 cursor 不等同已读完，has_more=true 必须继续或明确部分范围。仅列出的本人链接不代表完整 ACL。
3. organize / cleanup / recover 的返回可能是即时结果或后台 job。保存真实 job ID，按工具支持的操作类型查询；逐条核对 success / failure。取消本地等待不保证取消远端 job，也不能据此重发。
4. 文件请求是收集上传，分享链接是访问已有内容，不能互换。收集目录必须是实际 root/home 下已确认的子目录；拒绝根目标，不自动改成猜测路径。
5. copy、move、rename、delete、restore 的效果不同。冲突、autorename、共享影响和目标位置读取后按授权处理；恢复窗口和已删除状态依服务，不能保证任意数据可回退。
6. 文本提取 / Markdown / transcript 可能受大小、格式和后台处理约束。只读实际完成的内容，不从下载链接猜全文。上传、Paper 内容编辑和评论只用实际发现的工具；不执行来源附件或第三方脚本。

最小验收记录：账户与 namespace → 分页查找 → metadata / 内容 → 授权测试复制或移动 / 分享 / 文件请求 → job 终态与读回 → 过期 / 撤销。恢复及 Paper 能力按实际需要另验，不把现有六个来源技能的旧能力上限当永久合同。
