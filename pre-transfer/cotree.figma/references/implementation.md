# 设计到代码与映射

先取目标设计上下文与截图；大页面用 metadata 缩小节点后继续获取实际内容。读取项目组件、token、样式和测试入口，再选择映射。使用真实资产而非猜测图标；参考画面尺寸与浏览器复核尺寸保持一致。

复用项目语言和 UI 栈，识别组件实例、变量模式、布局约束、交互状态及无障碍名称。SwiftUI 映射关注 VStack / HStack / ZStack、系统控件、安全区、动态类型和语义颜色，不机械保留每个像素坐标。反向生成 Figma 时平台行为用说明补充，不能声称设计文件等于可运行应用。

Code Connect 必须使用真实组件 key、项目路径与导出名；同名不证明同一组件。确认 props / variants 的一致性，再校验映射文件和远端关联。设计系统规则写在项目现有规范位置，引用实际组件与 token。

交付前运行与改动相关的构建 / 类型 / 交互检查，在相同视口比较截图，复核溢出、间距、文字、图像和状态。分别说明读取、代码实现、浏览器验证和远端保存是否完成。
