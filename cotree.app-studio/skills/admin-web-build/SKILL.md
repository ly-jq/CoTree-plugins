读取运营角色、数据范围、流程与契约，沿现有设计和框架。列表、详情、操作和审计串成可用旅程；筛选分页、失败与部分批量失败按业务需要处理。

所有修改调用同一领域服务，不直写数据库绕过业务规则。越权操作直接请求 API 也应拒绝；前端禁用/隐藏仅提供体验。批量与高影响操作遵循用户产品要求，不凭空加入审批链。

与用户端核对同一记录在处理前后的状态和时间，使用隔离演示数据。交接实际入口、契约/代码版本、连接环境、权限负例及未覆盖范围；原成员负责后续修复。
