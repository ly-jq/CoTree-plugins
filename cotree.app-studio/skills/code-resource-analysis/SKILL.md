围绕本切片的信息缺口分析；先使用已有材料，不要求全量逆向。读取 [代码资源分析](../../references/resources.md)，登记来源、原件摘要、版本、平台、转换工具和研究/复用范围。

PluginCoTreeAppStudioReferences inventory 可列出资源，source-map 可分页读取 v3 源映射中的源文件索引与有界摘录；缺失 sourcesContent 时说明缺口。普通源码直接用现有搜索与 LSP，二进制分析经实际可用的 CLI/MCP。

跟踪界面动作→事件处理→请求/序列化→状态变化→异常分支，核对同版本运行证据。反编译名称或伪代码推断注明来源；不同构建的地址/函数不能拼接成同一调用链。

交付模块索引、候选规则、API 映射、正常/边界测试向量、复用建议及覆盖缺口。规则经 business 统一采用；开发按获准范围直接采用、封装适配或重新实现。不要从客户端按钮推断服务端授权，不把参考产品缺陷强制变成目标规则。
