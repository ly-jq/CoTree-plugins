# 浏览器 API 工作台

1.1.0 新增“操作流程”和随包 `browser-demonstration` Skill。需要同步构建本轮 Desktop、Bridge 与插件；单独替换旧宿主的 ZIP 不能增加页面录制能力。

1.1.1 修复 Skill 能力未声明导致模型无法发现/加载随包指南的问题。已有本轮录制能力的宿主只需更新插件；验收同时检查已安装 Skill 目录和真实模型的 Skill 加载结果。

1.1.2 将执行资源配额与已声明的 16 MiB 私有存储权限对齐，修复超过宿主默认 2 MiB 后无法保存流程的问题。原始录制仍归宿主分段加密存储，不计入插件定义库。

1.1.3 使用通用工具到 Service 绑定，复用已有插件宿主进程，减少连续查看步骤和读取固定选择的启动等待；空闲 5 秒回收。每次调用仍重新校验包及权限，能力配额独立计数。此版本需要随本轮源码构建支持 `tools[].service` 的宿主，不能只替换旧宿主中的 ZIP。

1. 在内置浏览器打开目标页面，再进入工作台的“操作流程”。展开“录制控制与历史记录”，明确选择标签，点击“开始录制”。
2. 操作网页。浏览器顶部可暂停、继续和结束；工作台还能标记手动步骤。结束后记录加密保存，同工作目录的其他对话可以读取。
3. 按步骤查看当时的请求。时间归组只是候选；可改名、合并、拆分、排序、重新归组或折叠。展开流程设置填写变量与完成条件，保存不可变版本。
4. 勾选步骤或接口，点“附加所选”，也可附加整个流程。卡片保留原草稿、不发送、不执行；重复附加同一选择只保留一张。大量选择保存成一个集合引用。
5. 在输入框说明新目标或新数据并发送。Agent 读取固定版本和 Skill，观察当前页面后执行，或使用当时样本配合当前登录态调用 API。可在样本详情收藏接口，实际调用仍遵循正常授权。

1.1.4 修复了返回插件时网页尚在加载，录制目标一直空白的问题。没有标签页时会提示先打开浏览器；尚未就绪、Agent 使用中和已有录制的标签显示具体原因。面板可见时，每 2 秒更新仍在等待的标签列表，全部就绪后停止；读取失败时逐步退避到 10 秒。也可点击“刷新标签页”。刷新保留按 sessionId/tabId 选中的页面，不因列表顺序变化选错标签。

工作台只在可见时刷新等待中的标签或增量读取正在进行的录制，不在后台持续轮询；标签检查仅调用 `capture.targets`，不重复读取历史或调用模型。默认每份最多 500 次操作、2000 个请求、8 MiB、30 分钟，宿主资产总计 128 MiB。到限明确暂停。无系统加密时仅保留有界内存记录，不能附加持久卡片；写盘失败可重试保存，损坏数据不会自动覆盖。

首版覆盖所选标签主文档的语义操作及 Fetch/XHR 请求，不录视频或响应正文。密码、认证/验证码字段在读值前排除；iframe、Canvas、弹窗、导航监听空档和未完成输入法组合明确显示缺口。用户需检查普通业务数据是否适合保存；可显式删除录制或固定版本，删除后旧引用会报缺失。

以下为保留的“全部接口”使用方式，与显式操作录制是两个独立开关。

默认使用“默认浏览器”，登录状态和 API 库跨工作目录共享，无需填写任何内部标识。插件不读取 cookie 明文，调用经宿主的 BrowserApi 工具完成。

1. Agent 页顶部“插件”→“浏览器 API 工作台”，或右栏添加面板→“浏览器 API”。工作台在右侧栏打开，当前对话保持可见。
2. 查看“使用指南”，保持自动记录开启，点击“打开浏览器”，登录后查询、筛选或翻页。回到 API 标签会刷新，也可手动刷新。Fetch/XHR 会自动入库，静态资源和登录提交不录制。
3. 选择有用的接口，编辑名称和用途，勾选“收藏，允许复用”并保存。
4. 填写 Agent 任务目标，点击“填入当前对话”，检查草稿并发送。原草稿保留；没有自动提交，凭证不会进入草稿。重复点击被抑制。
5. 请求参数与手动调用在“高级”折叠区。目录提供搜索和收藏筛选；录制可暂停。
6. 只有同一网站需要多个账号时，才展开“高级 · 多账号环境”。从列表选择已有环境，或新建“公司账号”“个人账号”等独立环境。选择/创建成功后会打开对应浏览器，浏览器顶部显示当前环境；新环境需要单独登录。切换失败保留原选择，登录状态及接口不会跨环境混用。

也可以直接告诉 Agent：“从浏览器 API 收藏中找到订单接口，帮我汇总最近订单。”Agent 按需加载 `PluginCoTreeBrowserApiManage` / `BrowserApi`，先 list/get 再 call。记录成功不代表 Agent 会在任意对话中自动调用。

1.0.4 必须配合 Desktop 0.1.88 的环境切换协议构建，不能独立替换旧版宿主。默认环境的存储位置及内部标识不变，已有登录状态和接口无需迁移。环境名称在已知环境列表中维护；暂不提供重命名或删除环境，以免误清账号数据。界面支持亮暗主题及 280px 面板。

认证字段的 `[REDACTED]` 占位符应保留；不能把接口移动到其他 origin。录制可随时暂停。401/403 需要重新登录。调用失败不会自动重试，未知结果应核对原请求而非重复提交。

从 Desktop 0.1.81 起，本插件随应用预装。Agent 页顶部“插件”菜单 → “浏览器 API 工作台”可直接打开；IDE 侧栏也保留入口。首次启动自动安装到全局目录并授权随包交付的精确摘要，无需另外下载 ZIP。用户主动禁用、卸载或撤销信任后不会被强制恢复；手动安装的不同包保留现状。独立安装 Code View 仍沿用 CoTree 的包摘要信任流程。构建入口：`node --import tsx plugins/cotree.browser-api/scripts/build.mts`。

1.0.1 将代理工具声明为 control 编排：外层不占用全局资源锁，内部 BrowserApi 继续经过资源锁、权限和审批检查，避免生产宿主中嵌套调用互相等待。插件启用授权不替代工具执行审批；出现 Tool approval pending 时需处理对应审批。
