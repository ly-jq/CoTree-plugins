从网页操作到 Agent 任务

  1. 登录网站打开内置浏览器，登录你要使用的网站。
  2. 操作并记录开启自动记录，再查询列表、切换筛选或翻页；回到此面板点击“刷新”。
  3. 收藏并交给 Agent选择有用的接口，填写用途并收藏。写下任务目标，填入对话后发送。

自动记录 Fetch / XHR 请求，过滤图片、样式等静态资源和登录提交；浏览器提供登录态，无需复制 cookie。
