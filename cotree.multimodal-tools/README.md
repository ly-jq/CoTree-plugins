# Multimodal Tools (`cotree.multimodal-tools`)

This first-party Code Plugin provides:

- `PluginCoTreeMultimodalToolsImageGenerate` for OpenAI image generation;
- `PluginCoTreeMultimodalToolsImageDescribe` for vision understanding.

Both execute in the ordinary out-of-process ABI v2 host. The plugin never reads an API key: `context.credentials.fetch` injects `IMAGE_API_KEY` or `OPENAI_API_KEY` only after the host validates the declared HTTPS destination. `PluginCoTreeMultimodalToolsImageDescribe` accepts a workspace-relative PNG/JPEG/WebP/GIF path, a public HTTPS URL, or bounded canonical base64. Generated bytes are returned as bounded ephemeral image content, while durable JSON contains metadata only.

Because the manifest declares credentials, the default `safe` Agent policy does not expose these tools automatically. Allow the plugin or individual tools in `pluginRuntime.agentTools.allow`; the Kernel's normal risk and approval policy remains authoritative.

Build a release package with:

```text
pnpm package:plugin -- cotree.multimodal-tools --output-dir .cotree/releases/plugins
```
